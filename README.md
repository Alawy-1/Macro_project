# Macro Project Information

The idea of this project is to excersize the and understand how the include statement works on programs. Include statements purpose is to expand the program file with the code itself for the compiler to process a complete code file. 

## Important Note 

There are three options for this program to operate:
1. Inner for loop runs
2. Outer for loop runs 
3. Both loops (complete loop cycle) runs

## Usage 

1. Define which option to run at the top of the code using the (#define option), replacing the "option" with (INNER, OUTER, BOTH). 
2. Run the program
3. Examine which loop is printed
